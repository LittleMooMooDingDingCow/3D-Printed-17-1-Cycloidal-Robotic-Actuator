# 3D-Printed-17-1-Cycloidal-Robotic-Actuator
17:1 and 25:1 Gear ratio cycloidal robotic actuator, powered by BLDC motor and runs FOC control based on B-G431-ESC1 development board and BHL firmware. New custom FOC drive board is under development.

WE highly recommend using the 25:1 gear ratio cycloidal robotic actuator for any robotic applications including robotic arms, automation, or humanoid robot. 

Since the original 17:1 robotic actuator is no longer under maintenance, as well as its torque-weight ratio is too low for any application that requires performance under high torque;


However, the original 17:1 actuator is still good if you prefer more responsiveness and less reflected inertia over torque margin;
Note that the two versions has a slightly different BOM since the new 25:1 actuator uses a different size sleeve bearing for its output shaft;

Furthermore, for any motor controller soldering, flashing, and programming implementation, please refer to this repo from the Berkeley Humanoid Lite team : https://github.com/HybridRobotics/berkeley-humanoid-lite.git


Lastly, for more specific guidance on how to use the B-G431-ESC1 with Berkeley Humanoid Lite Recoil Firmware, please refer to their website for tutorial here: https://berkeley-humanoid-lite.gitbook.io/docs/getting-started-with-hardware/building-the-actuator
